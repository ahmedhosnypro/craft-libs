# Proposal: `craft-metafile` — shared WMF/EMF metafile reader

**Status:** proposal (evidence only; no code extraction in this phase — humans decide)
**Target crate name:** `craft-metafile` (`crates/metafile`, named per AGENTS.md)
**Date:** 2026-10-13

## Why

Three Craft Apps carry a private `crates/metafile`, and this window contains the second
copy operation between apps:

- storytold/wordcraft: `crates/metafile/src` = `bytes.rs canvas.rs dib.rs emf.rs geom.rs
  lib.rs place.rs tests.rs wmf.rs` (HEAD `159b84f54c74e9e82fb3109b758ae7dd6f4e3ab0`,
  2026-10-12T16:08:57Z).
- storytold/vectorcraft: `crates/metafile/src` = `bytes.rs dib.rs emf.rs import.rs
  import lib.rs scene.rs tests.rs tests_import.rs wmf.rs` (listing via contents API).
- storytold/deckcraft#317 "Render: WMF and EMF draw (metafile reader ported from WordCraft)"
  (merged 2026-10-12T22:27:19Z, merge commit `f8d54d7af4a1e830eda2bf74cf9903010daabd2d`)
  — new `crates/metafile/` (Cargo.toml +13, src ~3,163 lines across `bytes.rs canvas.rs
  dib.rs emf.rs geom.rs lib.rs place.rs tests.rs wmf.rs`, incl. `tests.rs` 1,018 lines).

deckcraft#317's body states: "WordCraft's `crates/metafile` (same authors and licence;
bounds-checked, capped, no unsafe)". The code has now been copied app→app once (wordcraft →
deckcraft) with a third app (vectorcraft) carrying its own variant — the classic hoist
signal. The reader is generic: binary parsing of WMF/EMF records into geometry; no deck,
vector or document model involved.

## What the shared crate would own

- WMF/EMF record parsing (`bytes`, `wmf`, `emf`, `dib` modules).
- Record → geometry/scene translation (`geom`, `canvas`/`scene` equivalents).
- Placement/cropping math shared by picture pipelines (`place`).
- The test corpus (deckcraft#317 alone carries 1,018 lines of tests).

## What stays in each app

- How records map onto each app's picture/paint model (deckcraft tiles/recolor path,
  vectorcraft `import.rs`/`scene.rs` adapter).
- App-side renderers.

## Architecture compliance (target AGENTS.md)

- Useful to more than one app: three apps already run the code; deckcraft copied it from
  wordcraft this window.
- No app code: pure record parsing/geometry; no engine, no UI, no app dependency.
- New crate rules honored: `crates/metafile`, name `craft-metafile`, workspace-inherited
  fields/lints, `[workspace.dependencies]` registration, never-crash lint header, no unsafe.
- Gate commands before merging: `cargo fmt --check`, `cargo clippy --workspace
  --all-targets -- -D warnings`, `cargo test --workspace`.
- Scope check: parser/geometry only — not a renderer, not i18n, no binaries bundled.
